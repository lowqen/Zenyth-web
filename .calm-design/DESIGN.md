# Design System: Zenyth Web

> 2026-11-01 다시 씀(앱 디자인 정렬 Z0 ~ Z10, `docs/engineering-notes.md` §8). 2026-10-11 의 «먹과 한지»(따뜻한 종이 ·
> 흰 카드 + 테두리 · 초록 강조)를 걷고 **Zenyth 앱(안드로이드)의 지금 모습**을 따른다. 출처는 앱 코드
> `core/designsystem/**`(`Color.kt` · `Theme.kt` · `BoardSkin.kt` · `Tokens.kt` · `Type.kt` · `ChromeMotion.kt` …)이고,
> 값은 시험이 묶는다: 14램프 1,414값(`tokens.golden.json`), 대비 쌍, 스크린샷 골든 50장.

## 0. 원칙

1. **판이 주인공** — 화면을 연 사람이 가장 먼저 보는 것은 판이다. 보드 화면은 판 둘레까지 나무색으로 물든다.
2. **1초 안에 둔다** — 가운데 ▶ 하나가 엔진을 부르고, 결과는 요약 줄 한 줄로 온다.
3. **필요할 때만 펼친다** — 기본 다섯 탭. DB · 엔진 콘솔 · 엔진 파라미터 · PC 설정은 «고급 사용자 모드» 뒤.
4. **면으로 나눈다, 선으로 나누지 않는다** — 카드는 페이지보다 한 톤 어두운 무테 면이다.
5. **판 밖만 움직인다** — 크롬은 스프링, 판 · 평가 바 · 실시간 숫자는 «미끄러지지 않는다 · 200ms 이하».

말투: 짧은 평서문. 화면 문구는 «무엇을 하는지»만. 대시(— · –)를 쓰지 않는다(i18n 시험).

## 1. 색 — 역할 배정(`scheme.ts` = 앱 `Theme.kt`)

램프 값은 `ramps.ts`(앱 `Color.kt` 와 같은 14램프, 계산식 `oklch.ts`)이고 바꾸지 않는다. 바뀌는 것은 배정뿐이다.

| 역할 | 토큰 | 라이트 / 다크 |
|---|---|---|
| 페이지 | `--c-background` · `--c-surface` | `Mist` 99 / 10 (`#FCFCFF` / `#1C1B1E`) |
| 카드 면 | `--c-card` = `surface-container` | `Mist` 95 / 18 — 페이지보다 한 톤(대비 ≥ 1.06:1 이 경계) |
| 면 위의 면 | `surface-container-high` · `-highest` | 검색 알약 · 엔진 칩 · 배지 · 표 머리 |
| 진한 강조 | `--c-primary` | `Violet` 40 / 80 — 채운 단추 · 스위치 · 체크 · 진행 막대 · 섹션 머리 |
| 연한 강조 | `--c-secondary-container` | `Lilac` — 고른 칩 · 세그먼트 알약 · 내비 알약 · 아이콘 타일 |
| 글 | `--c-on-surface` · `-variant` | `Mist` 10 / 92 · `MistVariant` 30 / 80 |
| 의미색 | 결과 · 오류 · positive · caution | `Neutral` · 결과 램프 그대로 — `primary` 와 OKLab ≥ 0.08 떨어진다 |
| 판 | `--c-board-*` | 라이트 `Maple` 76 · 70 · 40 · 30, 다크 `WoodNight` 70° 같은 톤 |

- **나무색 팔레트**(`[data-wood]`, 앱 `WoodTheme`): 보드 화면의 상단 바 · 페이지 · 카드 · 키를 `Maple` 에서 뽑은
  색으로. ▶ 는 돌의 색(낮 먹 · 밤 흰). 다른 화면은 보라 그대로.
- **검은 배경**(`data-amoled`, 다크에서만): 페이지 0 · 컨테이너 6 · 10 · 14 · 19. 보드 화면은 면만 검정, 강조는 나무.
- 판 위 값 글자: 앱 `textInkAt()`(색 순서 그대로 · Oklch 채도 0.14 · 색마다 밝기).
- 초록(`Sage`)은 판의 마지막 수 · 후보 · «연결됨» 같은 **의미**에만.
- 그림의 색(«일식» 마크 · 아이콘)은 테마가 아니다: 메이플 `#DDB27C` · 진주 `#F6F1E9` · 먹 `#171513`.

## 2. 글자(`tokens.ts` = 앱 `Type.kt`)

- 글꼴: Pretendard 가변(저장소 안 npm, 동적 서브셋, OFL-1.1). `word-break: keep-all`, 숫자는 `tnum`.
- 페이지 제목 `headline-medium` 34 ExtraBold — 목록 화면(설정 · DB · 정석 목록) 맨 위, 스크롤하면 상단 바 한 줄로 접힌다.
  판이 있는 화면은 한 줄 머리만.
- title 22 / 17 / 15 · body 16 / 15 / 14(본문 기본 15) · label 14 / 12 / 11.
- 행: 제목 18(`row-title`) · 부제 15 회색(`row-note`), 최소 높이 64. 섹션 머리 15 SemiBold 강조색.
- 첫 실행 · 데이터 카드의 큰 제목: 26 ~ 30 ExtraBold, `text-wrap: balance`.

## 3. 리듬(`RHYTHM` = 앱 `Tokens.kt`)

화면 여백 16(좁은 폭도) · 카드 사이 12 · 카드 안 20 · 그룹 행 20 × 16 · 모서리: 카드 20 · 시트 32 · 알약 999.
넓은 화면에서도 «휴대폰 한 기둥»인 것(첫 실행 · 데이터 카드 · 시트 · 새로워진 점)은 480 안에 묶는다.

## 4. 부품

| 부품 | 모양 | 코드 |
|---|---|---|
| 카드 | 무테 면 · 모서리 20 · 그림자 없음. 떠 있는 것(메뉴 · RIF 진행)만 그림자 | `.panel` · `.card` |
| 연결 그룹 | 줄마다 제 면, 바깥 모서리만 카드 반경, 줄 사이 3px 틈 · 위에 강조색 섹션 머리 | 설정 하위 화면 |
| 단추 | 알약(카드 안 48 · 줄 안 40). 누르는 동안 모서리가 각지고 스프링으로 돌아온다 | `.cta` · `.btn` · `.ghostbtn` |
| 툴바 | 가운데 ▶ 84×56 · ‹ › 56×56 연한 강조 · 끝은 면 없는 44 아이콘. 끌어서 훑기 | `MoveToolbar` |
| 세그먼트 | 묶음 하나에 알약 하나가 미끄러진다 | `useSlidingPill` |
| 칩 | 고른 것은 연한 강조 채움 · 무테. 목록을 거르는 칩은 한 줄 가로 스크롤 | `Chip` · `ChipGroup row` |
| 배지 · 타일 | 사실 하나는 알약 배지, 줄 앞은 44 아이콘 타일(연한 강조) | `.pillbadge` · `.icontile` |
| 진행 | 둥근 막대 + 강조색 «3/8». 실시간 진행은 앞으로만 미끄러진다 | `.lprogress` · `SmoothFill` |
| 시트 | 아래에서 올라오는 모달: 손잡이 · 제목 · 내용 · 오른쪽 끝 [닫기] [확인] | `Sheet` |
| 묻는 상자 | 무엇을 정하는 물음(지우기 · 덮어쓰기)은 시트가 아니라 화면을 멈추는 상자 | `ConfirmBox` |
| 스위치 · 체크 원 | 켜지면 엄지에 체크 · 고른 줄 끝에 채운 체크 원(자라난다) | `Switch` · `.checkcircle` |
| 마크 | «일식» — 먹 돌이 진주 돌 앞을 지난다. 파비콘 · PWA 아이콘 · 환영 · 새로워진 점 · 정보 | `ZenythMark` · `public/` |

빈 상태는 «없음»을 늘어놓지 않고 무엇을 하면 채워지는지 한 줄(랭킹의 «대국 데이터를 넣으면 표시»).

## 5. 배치

- 셸: 넓은 폭은 레일, 640 미만은 하단 탭. 고른 항목 = 채운 아이콘 + 연한 알약 + 굵은 라벨, 나머지 외곽선.
  기본 5(보드 · 연구 · 정석 · 엔진 · 설정), 고급 사용자 모드면 DB 를 더해 6.
- 보드: 머리에 제목 없이 [분석] | [대국] · 엔진 칩 · 테마. 넓은 폭 2단(판 | 요약 줄 + 카드), 640 미만 세로는 판 ·
  툴바 고정 + 스냅 바텀시트(피크 = 손잡이 + 요약 줄). 다른 화면에서 엔진이 돌면 하단 탭 위 미니 분석 바.
- 연구: 리뷰 · 오프닝 · 수순 · 랭킹 세그먼트. 오프닝 · 랭킹은 실전 대국 데이터가 없으면 맨 위에 그 카드.
- 설정: 큰 제목 · 알약 검색 · 줄(디자인 · 일반 · 엔진 / 고급 사용자 모드 · PC 설정 / 정보) → 하위 화면.
- 첫 방문: 환영 한 화면(언어 알약 · 기능 줄 셋 · 시작하기). 둘러보기는 설정 ▸ 정보에서만.

## 6. 움직임(`springs.ts` = 앱 `ChromeMotion.kt`, `MOTION` = 앱 `Motion.kt`)

| 무엇 | 어떻게 |
|---|---|
| 판 · 평가 바 · 실시간 숫자 | 미끄러지지 않는다 · 200ms 이하 · 숫자는 보간하지 않는다 · 증명 하트비트 500ms |
| 작은 부품(단추 모핑 · 칩 · 체크 · 세그먼트 알약 · 쪽 점) | `--spring-spatial-fast`(ζ0.6 · k800, 348ms) |
| 시트 · 보드 시트 · 목록 항목 | `--spring-spatial`(ζ0.8 · k380, 412ms) |
| 불투명도 · 색 | 넘치지 않는 곡선(`effects`) |
| 목록 첫 등장 | 처음 10개 · 40ms 간격 · 12px · 그 목록을 처음 볼 때만(`useStagger`) |
| 진행 막대 | 앞으로만 200ms, 뒤로 · 처음 · 끝은 바로(`SmoothFill`) |

스프링은 질량 1 스프링의 해를 `linear()` 로 구운 것(`linear()` 를 모르면 같은 성질의 3차 곡선).
`prefers-reduced-motion` 이면 길이 0 에 더해 스태거 · 평활까지 끈다.

## 7. 반응형

- <640px: 하단 탭 · 보드 시트 · 터치 타깃 44(최소 24). 시트는 화면 폭, 넓으면 아래 가운데 560.
- ≥640px: 레일 · 보드 2단 · 넓은 화면에서도 읽는 기둥은 640(`--reading-width`).

## 8. 하지 않는 것

- 카드에 테두리 · 그림자, 면 위에 같은 면(한 단 위로 올린다)
- 한 카드에 채운 단추 둘 이상
- 판 위나 실시간 숫자에 스프링 · 보간
- 브라우저 기본 상자(`window.prompt` · `confirm`) — 시트 · `ConfirmBox`
- 색 hex 를 `base.css` 에 직접 — 토큰만(그림의 색과 판 렌더러 예외)
- 엔진 내부 이름(multi-simd128-relaxed · YXNBEST)을 첫 화면 글로 — 툴팁
- 화면에 «왜»를 늘 펼친 문단 — 한 줄 + 펼침
